# FMUCD v1 code distribution by sampled university

Counts cover all 4,393 complete rows in the 13 verified pilot slices, including duplicates and planned work. Columns `U1`, `U4`, and so on are the publisher's `UniversityID` values. `U1` is the frozen validation university and `U4` is the frozen test university. These are raw audit counts. The label proposal applies additional screening after the Milestone 10B split.

Descriptions and codes are the values in `SystemCode` / `SystemDescription`, `SubsystemCode` / `SubsystemDescription`, and `DescriptiveCode` / `ComponentDescription`. Each level totals 4,393 independently. The blank code is reported as it appears in the source. [FMUCD v1 by Pampana et al. (CC BY 4.0)](https://data.mendeley.com/datasets/cb8d2nsjss/1) · [Publisher data dictionary](https://pmc.ncbi.nlm.nih.gov/articles/PMC11465139/#tbl1)
